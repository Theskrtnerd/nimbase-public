# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email
`nimbase.ai@gmail.com` with the subject “Security report” and include a
description, reproduction steps, affected version, and any suggested
mitigation. Avoid including live customer data or secrets.

We will acknowledge a report as soon as practical, investigate it, and
coordinate disclosure and remediation with the reporter. Please allow a
reasonable remediation window before public disclosure.

## Supported versions

Security fixes are applied to the latest release and the hosted Nimbase Cloud
service. Community operators are responsible for tracking releases and
upgrading their deployments.

## Deployment responsibility

Self-hosted operators control authentication configuration, encryption keys,
network exposure, backups, provider credentials, and update cadence. The
self-hosting guide documents a development baseline, not a hardened production
configuration.
