# company.md structure

The file is short (~300 words max) and always follows this shape:

```markdown
# <Company name>

<One-or-two-sentence plain statement of what the company is, grounded in the
description/website. If a website URL is known, end the paragraph with it as
a markdown link.>

## What we do

<2-4 sentences. Products/services actually evidenced in the inputs.>

## Who we serve

<1-3 sentences. Only audiences the inputs support; if unknown, say the memory
will fill this in as knowledge arrives.>

## How this memory is organized

<2-3 sentences: knowledge is captured into this workspace; an AI gardener
keeps notes coherent in one centralized knowledge base; connected sources
retain the access rules derived from their providers.>
```

Never add sections beyond these four. Never include a logo image inline —
branding assets live outside the note.
