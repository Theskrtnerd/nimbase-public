# Grounding answers in the wiki

- Start with the `search` tool for concepts, `grep` for exact strings or
  `[[wikilinks]]`, `ls`/`glob` to see how a topic area is organized.
- Read the actual note bodies before answering — summaries and search
  snippets are hints, not sources.
- Cite every note you relied on by its wiki path (without the `/wiki` mount
  prefix), e.g. `source: team/onboarding.md`.
- If multiple notes conflict, say so and cite both; prefer the more recently
  updated note when you must pick.
- Company-specific claims that aren't in the wiki don't exist for you: say
  you don't have that information.
